Version 1.4.4 — 24 November 2026

TailRef Studio 1.4.4 adds native macOS builds for Apple silicon and Intel, opens .tail boards straight from Finder, and fixes a long list of settings that saved a value without applying it.

  • macOS: separate arm64 and Intel disk images, built and launched as part of the release check.
  • Finder integration: double-clicking a .tail board opens it in the running window or starts TailRef with it.
  • Settings audit: high contrast, custom themes, cursor-anchored zoom, editor grid step and the narrow-panel layout now work as labelled.
  • Ten languages with no key falling back to English.
