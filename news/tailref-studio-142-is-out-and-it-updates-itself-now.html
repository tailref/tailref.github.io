TailRef Studio 1.4.2 is out — and it updates itself now

21 November 2026 Emre Melik Nameli 2 min read

TailRef Studio is now on itch.io. TailRef is a free, open-source Windows workspace for artists who work from references: collect references, draw over them and pose 3D models in one window.

Version 1.4.2 is the first build published here, and it is mostly about keeping the app current and safe.

Automatic updates

  • The installer build now updates itself from GitHub Releases. It checks 25 seconds after launch and every 4 hours, and you can check manually from Settings > About.
  • Checks never block startup. If an update is ready while you have unsaved work, TailRef asks before restarting: save and restart, restart without saving, or cancel.
  • Skipped versions stay skipped on automatic checks but can still be installed manually.
  • The portable build points you to the download page instead of updating in place.

Licence

TailRef is now distributed under GPL-3.0-or-later. Commercial use, modification and redistribution are allowed under the GPL; the full source is on GitHub.

Security

Full audit pass: file path policy, outbound connection allowlist, Electron fuses, CSP, sandbox and webview hardening, plus a secret scan. Electron is updated to 45.4.1.

Download

Two builds, both 1.4.2: Installer (recommended, self-updating) and Portable (no installation). Windows 10/11, 64-bit. Free — if it saves you time, you can leave a tip.

Source, changelog and checksums: github.com/Roxsmb/tailref/releases
